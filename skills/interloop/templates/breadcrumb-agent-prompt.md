A git commit just occurred in this repository. Capture a rich breadcrumb entry without blocking the coding agent (you are running async).

Run these two commands:
1. `git log -1 --format="%h|%s|%b"` — short hash, subject, body
2. `git diff HEAD~1 --stat 2>/dev/null || git show --stat HEAD` — changed files summary

Then append to `.interloop/breadcrumbs.md` using this exact format (blank line after each entry):

```
## HH:MM — commit <short-hash> · <subject>
Files: <condensed list, e.g. "auth.ts, middleware.ts, tests/auth.test.ts (+3 files)">
What: <1-2 sentences describing the behavior change in plain language, not file names>
Decided: <any architectural or approach choices made, or "n/a">
Uncertain: <open questions or things the author flagged as unsure, or "n/a">

```

Rules:
- Never more than 6 lines per entry
- For "Uncertain": scan commit body for TODO, FIXME, "not sure", "need to", "?", or hedging language
- For "What": describe what the code now does differently, not what files changed
- If `.interloop/breadcrumbs.md` doesn't exist, create it with `# Breadcrumbs\n\nGenerated by coding agent hooks. Do not edit manually.\n\n` before appending
- Keep it compact — this file is read by a human scanning for context gaps
